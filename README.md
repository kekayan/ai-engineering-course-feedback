# AI Engineering course: feedback

Comments and problem reports for the [AI Engineering course](https://kekayan.dev/ai-engineering-course/).

- **Comments**: each lesson has a comment thread at the bottom of the page. Each thread is stored here as one issue labelled `comments` (via [Utterances](https://utteranc.es)).
- **Problem reports**: the "Report a problem" button on a lesson opens an issue form here, labelled `lesson-feedback`, with the lesson's URL and any text you selected already filled in.

You need a GitHub account to comment or report.
